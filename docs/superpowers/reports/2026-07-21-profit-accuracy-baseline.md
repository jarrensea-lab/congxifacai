# 盈利与预测准确度冻结基线（2026-07-21）

## 口径

- 数据根：`data/prediction_lab` 的 append-only prediction/outcome ledger。
- 去重：按 `prediction_id` 取终态，跨版本样本不混算晋级。
- 盈利：只有完整 `signal -> authorization -> recommendation -> fill -> terminal outcome` 归因链进入策略盈利指标。
- 成本：必须有可交易手数、进出场策略、双基准和实际佣金；估算佣金只展示，不允许晋级。

## 结论

本轮优化修复的是数据真实性、授权幂等、风控闸门、成本口径和归因链可达性，不能据此声称预测准确率或盈利能力已经提高。后续新样本只有同时具备双基准、可交易预算、实际佣金和完整执行归因，才有资格进入晋级比较。

下一次允许声称“提高”的最低证据为：至少 60 个同口径独立样本、至少 20 个交易日、coverage 不低于 90%、相对 `price_action_v1` 的配对准确率与成本后净期望 95% CI 均排除 0，且回撤不超过账户档位上限。
